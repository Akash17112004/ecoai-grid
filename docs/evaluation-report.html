Limits of this evaluation

  • All hardware is simulated; the simulator shares the controller's model structure, so the forecast accuracy is optimistic until the real rig is logged.
  • Results describe this scale model and these fault schedules only.
  • Water is a trade-off, not a saving: the optimiser prefers the liquid loop because it is cheap in electricity.
